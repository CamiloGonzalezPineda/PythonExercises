# 🐍 Python para automatización de pruebas

Repositorio de práctica con ejercicios desarrollados durante el **Sprint 7 de QA Engineering en TripleTen**, enfocados en los fundamentos de Python y su aplicación en escenarios de prueba de software.

El objetivo es documentar los conocimientos adquiridos y conservar ejemplos prácticos basados en situaciones simuladas de **Urban Routes**.

## Configuración y ejecución

### Requisitos

- Python 3 instalado.
- Visual Studio Code (recomendado).
- Git.

### Instalación

**1. Clonar el repositorio**

```bash
git clone URL_DEL_REPOSITORIO
```

**2. Acceder al directorio del proyecto**

```bash
cd sprint-7-python-practice
```

**3. Ejecutar los ejercicios**

```bash
python3 sprint_7_python_exercises.py
```

> No se requieren dependencias externas para ejecutar los ejercicios.

## Conceptos practicados

Durante este sprint se trabajaron los siguientes fundamentos de Python:

- Tipos de datos y expresiones booleanas.
- Estructuras de datos: listas y diccionarios.
- Condicionales y operadores lógicos.
- Bucles e iteraciones.
- Funciones integradas de Python.
- Creación y reutilización de funciones.
- Parámetros y argumentos.
- Devolución de valores mediante `return`.
- Validación de condiciones mediante `assert`.

## Aplicación en QA

Los ejercicios utilizan datos simulados de Urban Routes para practicar situaciones relacionadas con el aseguramiento de la calidad del software:

- Consultar y manipular información de viajes.
- Validar estados y códigos de respuesta HTTP.
- Contabilizar tiempos de respuesta que superan determinados umbrales.
- Calcular tarifas y tiempos estimados de viaje.
- Comprobar reglas de negocio mediante condiciones y aserciones.
- Validar resultados obtenidos mediante funciones.
